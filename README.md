## Explore the Library

A single application for discovering and managing BeamNG.drive modifications.

The library is divided into dedicated sections to make browsing easier.

### Cars — Vehicle Collection

Explore community-created vehicles for BeamNG.drive.

Browse vehicles by manufacturer and category, view available configurations, inspect preview images, and read listing descriptions before downloading.

Available library features include:

- Vehicle brand filtering
- Sorting and searching
- Vehicle previews
- Creator information
- Version information
- Favorites
- Community ratings and reviews
- Installation management
- Compatibility information when provided

Every available vehicle is displayed in the desktop catalog.

### Maps — Environments and Locations

Discover downloadable environments created for BeamNG.drive.

The Maps section provides an organized way to browse available environments without manually searching through unrelated files.

Each published listing can include a description, preview media, and relevant installation information.

### Extra — Additional Modifications

Explore other supported modifications through the Extra section.

This category is intended for community-created content that does not fit within the primary vehicle and map categories.

All categories are managed from the same application.

## Why Use BeamNG Mod Library?

### One Centralized Library

Cars, maps, and additional modifications can be found in one organized interface.

Browse the available collection without navigating through numerous download pages.

### Automatic Installation

The application handles supported mod downloads and installation.

Once a mod has been downloaded and validated, the application installs it into the configured BeamNG.drive mod directory.

The default destination is:

`BeamNG.drive/current/mods/repo`

Users can configure the appropriate folder when required.

### Arabic and English

The application supports both Arabic and English.

Language preferences are saved independently for the member library and administration interface.

Users can switch between supported languages from the application.

### Downloads and Installation Management

The download system supports:

- Download progress tracking
- Cancellation
- Resumable downloads
- Archive integrity checks
- Duplicate detection
- SHA-256 verification
- ZIP structure validation
- ZIP entry CRC verification
- Installation verification
- Backup creation before replacement

The application is designed to reduce problems caused by damaged downloads and incompatible ZIP structures.

### Favorites and Reviews

Members can save preferred listings for easier access.

Each verified member may submit one rating per listing and update that rating.
